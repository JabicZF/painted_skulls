# painted_skulls
A small datapack that lets you paint wither skeleton skulls into skeleton skulls

Wither Skeleton Skulls can be crafted into Regular Skeleton Skulls by dyeing them white, and Skeleton Skulls can be crafted into Wither Skeleton Skulls by dyeing them black.
